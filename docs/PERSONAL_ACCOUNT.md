# Roppo 个人本地账号

本版为每个部署提供一个本地账号。无需官网注册、邮箱验证码或许可证。账号用于进入工作台；模型 API、订阅和 CLI 的授权继续独立管理。

## 开始使用

在当前项目中运行：

```sh
npm ci
./start.sh
```

启动器会自动打开默认浏览器。首次显示“创建你的账号”，填写称呼、用户名和密码，保存恢复码后进入工作区。已有账号但未登录时显示登录页；记住登录仍有效时直接进入工作区。默认记住登录 30 天；取消勾选则使用最长 12 小时的浏览器会话。使用同一状态目录和浏览器时，尚未过期的记住登录会在宿主重启后保留。

`./start.sh`、`npm start` 与 `./start.sh setup` 都使用个人启动流程。再次运行会复用已有宿主，并重新打开入口，不会重建账号或覆盖配置。源码运行仍要求安装 Node 22.19+ 并先执行 `npm ci`。

个人安装目录默认是 `~/.agent-hub`，也可使用 `./start.sh setup /path/to/private-directory`。已有配置继续使用 `./start.sh serve /path/to/config.json`，不会迁移任务或改写模型配置。

首次初始化授权由启动器自动传入浏览器，页面随后移除 URL 中的一次性凭据，正常使用不需要手动复制配对链接。设置过期时，再次运行原启动命令。自定义部署可用以下命令自动打开入口：

```sh
./start.sh open http://127.0.0.1:PORT /path/to/state/access-token
```

创建账号后，新的启动链接仍要求登录，不再代替账号密码。日常直接打开 `/configure` 即可。侧栏的个人头像进入 `/account`，可修改称呼和密码、重新生成恢复码、退出当前或所有浏览器会话。

无图形界面、SSH 或 CI 环境会保留终端链接，不自动打开浏览器。显式手动模式为 `./start.sh setup [安装目录] --no-open` 或 `./start.sh open HOST_URL TOKEN_FILE --no-open`。自动打开失败时宿主继续运行，终端给出备用入口。`serve CONFIG` 保持手动/服务部署行为，不弹出浏览器。

## 找回与会话

- 恢复码只在创建或重新生成时展示，可复制或下载。下载文件包含用户名；应私下保存。
- 忘记密码时，在登录页选择“忘记密码”，输入用户名、恢复码和新密码。恢复成功后旧恢复码与所有旧浏览器会话失效，并展示新的恢复码。
- 修改密码会退出其他浏览器会话，当前浏览器换发新会话。
- 已登录且记得密码时，可重新生成遗失的恢复码。
- 退出网页账号不会删除模型连接、CLI 凭据或任务。

## 存储与边界

账号文件为状态目录中的 `personal-account.json`，权限为 `0600`，通过原子文件替换写入。密码采用固定参数 scrypt；恢复码和会话令牌只保存哈希。前端不把密码、恢复码或会话令牌写入浏览器存储，登录凭据通过 HttpOnly、SameSite=Strict cookie 保存。短时失败次数会持久化，连续 8 次失败后暂停尝试 15 分钟。

管理接口验证真实会话，跨来源浏览器写请求会被拒绝。原有 bearer 令牌继续供本机 CLI / MCP 使用；持有该机器凭据意味着仍拥有其管理能力。Worker 和消息入口沿用原来的独立身份。宿主仍只监听 loopback，本版没有增加远程服务或多用户组织权限。

账号格式有版本号；损坏或不支持的账号文件会阻止启动，不会自动清空或重建。任务/配置备份不包含账号文件，恢复旧任务配置也不回滚密码。迁移整个个人部署时，应在停止宿主后单独妥善备份账号文件；将账号文件恢复到旧版本也会恢复其中旧的会话状态，恢复后应登录并退出所有会话。

## 验证

`tests/personal-account.spec.ts` 覆盖启动授权、并发唯一账号、持久登录、cookie/来源检查、输入校验、改密撤销、恢复码轮换、失败限流、损坏数据、任务备份恢复不回滚账号，以及页面脚本语法。现有 CLI / 入口与配置回归保持通过。

真实浏览器验收使用独立、暂停的宿主和测试账号，不调用模型服务：

```sh
npx tsx examples/personal-account-preview.ts .local/account-check
.local/browser-venv/bin/python tests/browser/personal_account.py .local/account-check .local/account-evidence
```

浏览器脚本要求首次运行目录尚未创建账号；重复验收应使用新的隔离目录。历史截图与报告留在本机私有验收目录，不随源码发布。运行脚本前需准备安装 Playwright 的 Python 虚拟环境。截图证明本地界面和账号流程，不代表真实模型、外部消息入口或组织版已验收。

2026-11-07 的自动启动回归新增 `tests/personal-launch.spec.ts` 和 `tests/browser/personal_launch.py`：覆盖原生打开程序的参数、无界面/失败回退、真实 CLI 首次/复用/重启、首次建号、未登录提示及记住登录直达工作区。浏览器集成测试使用记录调用的系统打开程序替身，随后在真实 Chromium 中访问同一入口；它不等同于各操作系统的原生浏览器唤起验收。
