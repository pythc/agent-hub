# 2026-11-14 三平台自主任务验收

## 范围与方法

本次先完成内置 Chat 的 Agents 列表改造：名字下面显示该 Agent 最近一条消息，未发言时显示“暂无消息”；设置中的显示方式统一称为“Agents 列表”。Worker 上下文仍只读，用户向 Router 派活。

外部验证使用真实飞书测试群聊、Slack 测试频道、Linear 测试 issue，真实 Codex 模型及官方 GitHub MCP。通过平台发自然语言请求，由 Router 决定任务和 Worker，不在请求中指定调查、实现、测试等分工。使用独立验收状态目录及工作区，避免测试覆盖日常状态。

“单 Worker”指一个完整任务由同一 Worker 负责；并行的不同任务可以占用不同 Worker。独立验收器不承担实现。宿主修复和恢复操作单独记录，不能据此宣称所有场景第一次请求即成功。

## 本轮产品修复

- **新增入口不再无故撤销已有任务上下文。** 修改或禁用已有绑定仍会使旧权限失效。
- **工具发现返回紧凑列表，按需读取单个工具 schema。** 大回执可由原任务分页读取，保留任务、assignment 和上下文权限校验。
- **允许联网的任务继承宿主标准代理变量。** 禁止联网的任务仍不继承代理；未向 Worker 暴露账户令牌。
- **恢复原生 Worker 会话时挂载当前工具桥。** 保留原线程、任务及预算，避免因为工具 schema 变化启动失败。
- **验收输入包含真实外部工具结果。** 不再只给工具名称；保留失败、未决、截断及跨任务隔离边界。
- **定时提醒由宿主回传原入口。** Router 无需另找发送工具，简单提醒也不再依赖被提醒任务已经完成。
- **所有任务验收统一使用短证据编号及每项可引用范围。** 重试带回上一轮协议错误；账本继续保存完整证据 hash，未读完或不属于该项的证据仍不能通过。
- **按用户要求交付完整文档。** 去掉日常回复的 100 词硬上限；日常进度仍保持简短。
- **重启保留原有未决错误。** 不用泛化的“宿主停止”覆盖已知 provider preflight 错误。
- **浏览器截图走现有专用浏览器。** 导出为本任务只读 PNG 附件；允许工作区写入的任务同时获得直接落在工作区的 `workspacePath`，避免原生模型对宿主 state 目录的禁读策略冲突。保留原始文件、hash 和宿主捕获回执，不需要扩大普通 shell 权限。沿用会话归属、接管和去重校验。
- **验收包含已接收的人类后续要求。** 后续要求与原始任务一起评审，保留不可变授权边界，并继续排除已隔离的旧上下文。
- **浏览器导航、点击结果进入验收。** 新回执包含任务和 assignment 归属，按任务提供原始结果、状态、hash 与截断标识。不会根据相同 Worker 或 URL 猜测历史无归属回执的所有者。
- **工具变化通知原 Worker。** 恢复时自动给出当前工具目录，重新检查旧的能力阻塞判断；保持线程和工作区，不手动指定实施方法。

## 失败尝试与运行边界

- 飞书首次请求在新增另一个入口后失去上下文权限；保留原失败记录，修复入口绑定逻辑后重新发送请求。
- Slack 首次文档请求被验收要求附件交付阻塞。当前插件只配置了读消息/线程及宿主文字回复，没有附件上传；后续明确要求本机交付才完成。附件上传不计为通过。
- Linear 原任务经历仓库网络访问失败、恢复工具 schema 失败和验收引用协议失败。恢复保留同一原生 Worker 线程，没有通过替换任务或直接写文件绕过验收。
- Linear 首次通过验收只交付了摘要，漏掉后来补充的全文要求。已修复验收缺失后续要求的问题，并通过另一条自然语言请求完成实际全文交付；不能声称原任务一次性满足了所有追加要求。
- GitHub 另以自然语言要求同步 PR 说明，Roppo 自行更新并回读 open/draft/未合并状态。该新任务未取得先前 Worker 的命令回执，因而没有把早先测试陈述当成本次执行证据；本报告的 Node 24 结果来自独立检出复核。
- Slack 发送连接器将含普通网址的浏览器请求截坏。直接读取 Slack 原文确认后，使用内联代码格式重新发送完整网址。此问题发生在发送端，不归因于 Roppo 入站解析。
- 浏览器任务经历普通 shell 无法启动 Chromium/WebKit、旧工具能力认知、宿主附件目录禁读，以及导航证据缺失。每次均修改宿主实现、保留数据库备份并恢复原 Worker；截图业务文件由该 Worker 自己从宿主交付的工作区文件生成。最后一次恢复将验收修复额度从 2 调整为 3，未清零历史失败、替换任务或直接修改验收结论。
- 记忆工具当前只支持查询、检查和提议；删除通过管理界面执行。自然语言“忘掉”没有删除记录，不能计为自动遗忘成功。测试结束后，通过既有管理 API 只删除临时偏好这一条，读回为 `tombstoned`、正文为空；保留会话与外部原消息。
- Linear 使用个人 API key 及评论身份，不是机器人身份；未授予 issue 状态写权限，不能宣称验证了状态变更。
- 本轮真实定时执行覆盖一次性提醒，不等于长期跨重启、夏令时或任意重复周期均通过实测。
- 本轮指南任务核实部署源码与文档，不能替代 Docker 实际构建、启动和升级回滚验证。
