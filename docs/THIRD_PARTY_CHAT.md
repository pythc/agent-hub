# 站内对话开源组件

本页根据当前锁定依赖的 `package.json` 与发布包许可文件核对。完整许可证随 npm 包安装；副本保留在 `licenses/chat/`。

| 依赖 | 固定版本 | 许可 | 使用范围 |
| --- | --- | --- | --- |
| @assistant-ui/react | 0.15.32 | MIT | 对话、输入框、历史列表、运行时适配 |
| @assistant-ui/react-markdown | 0.14.24 | MIT | Router Markdown 回复 |
| react / react-dom | 19.3.1 | MIT | 页面渲染 |
| lucide-react | 1.70.0 | ISC | 图标 |
| vite | 8.3.6 | MIT | 构建工具 |

Roppo 布局和宿主适配自行实现；未整站复制 Vercel AI Chatbot 或 LibreChat。assistant-ui 使用本地组件，不启用其云端服务。Roppo 标志沿用本项目资产。
