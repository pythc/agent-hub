# Roppo 内置浏览器

浏览器位于会话右侧，与“文件”和“团队动态”共用标签面板。右上角按钮可以收起或打开面板；左侧不再提供独立的浏览器入口。Router 继续负责沟通和分派，Worker 通过宿主工具操作各自的浏览器；没有引入第二套模型规划循环。

## 使用

1. 创建浏览器资料，在里面手动登录网站，或从钥匙按钮保存账号并选择“填入”。填入后由你或 Worker 确认提交；验证码和二次认证可以人工完成。
2. 在浏览器资料设置中选择允许复用这些登录信息的 Worker。每个 Worker 默认可以使用空白独立浏览器，个人登录资料必须另行授权。
3. 向 Router 提交网页任务。浏览器标签只显示当前会话的个人浏览器与 Worker 实例，可查看实时画面、网页标签页和控制状态。
4. 点击“接管”后，由宿主完成控制权交接。结束后点击“交还 Worker”，Worker 收到继续执行的输入，必须获取新的页面快照。另一窗口需要点击“转移控制到此窗口”才能取代原操作者。

支持鼠标点击、滚轮、文字/粘贴/输入法、常用按键与全选。远程输入区按 F6 回到地址栏；Escape 可操作远程页面，账号弹窗的 Escape 只关闭弹窗。支持黑白主题、展开面板和窄屏；页面本身无外层滚动。

## 持久化与隔离

浏览器资料与已保存账号仍可在自己的会话中选择，但一个正在使用的个人 profile 只能绑定一个会话；要在另一会话使用，请另建资料，或先关闭原实例。Worker 登录复制仍按授权执行。

个人浏览器使用独立 Chrome profile，保留网站持久 Cookie、站点存储和标签页网址/当前标签页。普通关闭与宿主重启后可重新打开。Worker 每个 assignment / 子代理获得不同的浏览器进程会话和可写目录，不共享个人 profile，也不能操作其他 assignment 的页签。

复用个人登录时，先导出授权资料，再仅复制目标网址对应的 Cookie 和 origin 存储到任务浏览器。Worker 的后续修改不回写个人资料。多个浏览器使用同一网站账号时，网站服务器上的业务数据仍属于同一账号；本地浏览器隔离不能消除网站业务层面的写入冲突。涉及这类任务应由 Router 串行安排，或使用不同网站账号。

同一会话内的命令串行执行。人工接管先阻止后续 Worker 命令，再等待已开始命令结束；旧控制权代次、旧快照和旧标签页引用会被拒绝。人工控制租约失效后保持暂停，不自动恢复 Worker 写操作。任务结束时回收任务浏览器；已交给人的浏览器保留供检查，不能继续由旧任务操作。后台闲置实例会按配置回收。只有正在观看的浏览器开启画面流。

`superagent_browser` 是 API 后端和原生 Codex Worker 共用的实际工具，提供 profiles、open、navigate、snapshot、click、fill、press、scroll、标签页、login、request_takeover 和 close 操作。元素操作必须携带最近快照的 revision，标签页使用稳定 `t1` 等 ID。相同 requestId 不重复执行；超时或宿主中断后的未确认写操作不会自动重放。

## 密码和安装

保存账号由 Roppo 的本地账号库提供，不依赖 Chrome 的密码保存弹窗。密码使用 AES-256-GCM 加密，密钥文件仅宿主用户可读写；也可指定密钥环境变量。工具只传 credentialId，密码经标准输入送入浏览器，不进入命令行参数、普通记录表或工具回执；已知保存密码在返回模型的页面快照中被过滤。不会导入用户日常 Chrome 的密码库，也不提供云同步。

删除保存账号只删除密码记录，不会让网站现有登录失效；需要退出网站时，应在对应浏览器里执行网站的退出登录。

运行依赖固定 `agent-browser 0.27.0`。macOS 默认使用已安装的 Google Chrome；其他宿主可指定 `browser.executablePath`，或安装工具使用的 Chrome：

```sh
npm ci
npx agent-browser install
npm run build:chat
```

顶层配置示例（其余配置沿用原文件）：

```json
{
  "browser": {
    "enabled": true,
    "maxSessions": 8,
    "timeoutMs": 20000,
    "idleMs": 900000
  }
}
```

`maxSessions` 包括个人和任务浏览器。`browser.command` 可指定兼容的引擎可执行文件；`browser.keyEnv` 可指定包含 64 位十六进制密钥的环境变量。不要在已有账号库上直接更换或丢弃密钥。

在 Worker 配置的工具页可以单独关闭浏览器访问、设置标签页上限；对应每个 `execution.workers[]` 的 `browser: {enabled, maxTabs}`。设置沿用现有任务配置生效规则，个人资料授权则每次调用都会重新检查。

浏览器数据位于 `<stateDir>/browser`。现有数据库备份命令不包含整个 Chrome profile：迁移或备份时应停止宿主，同时保存数据库、该目录及外置密钥。只恢复数据库不能恢复登录信息，丢失密钥无法还原保存密码。网站会话有效期、跨站 SSO、设备绑定及二次认证仍由网站决定；不会承诺永久登录或跨机器无条件迁移。

当前验收覆盖 macOS + 本机 Chrome。Linux/Windows、任意外部网站、Chrome 扩展、下载/文件选择、系统 Passkey 和复杂跨站登录流程未计入通过项。见[验收记录](BROWSER_ACCEPTANCE_2026-11-07.md)及[开源许可](THIRD_PARTY_BROWSER.md)。
