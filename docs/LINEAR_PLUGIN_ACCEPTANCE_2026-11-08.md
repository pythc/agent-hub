## 功能与权限

- Issue／评论入站；按实际工作区、团队、可选 Issue 范围过滤，团队成员与账号身份核验。
- Worker 通过已授权 trigger 读取原消息、Issue 详情和分页评论；Router 通过原有 outbox 回写原 Issue。
- 固定更新窗口、分页检查点、重启续读、重复观察去重、GraphQL 部分失败拒绝、限流退避。
- 编辑／归档内容失效；读写前检查原文和实际团队；发送前持久化自身评论标记；发送结果不确定时保留待对账状态。
- Linear 的工作流状态不改变 AgentHub 的目标、授权或验收标准。此版本写入能力限定为评论；不包含通用 Issue 修改、Webhook 服务、Linear Agent Session 协议或 OAuth 自动续期。

经用户即时确认，创建 `AgentHub Linear Validation` 个人 API Key，仅选择 `Read`、`Create comments`，平台团队范围限定为 `Alexcyzhou / ALE`。文件保存在仓库外，权限 `0600`。实际主体为用户账号，评论归属于用户，不冒充独立机器人。
