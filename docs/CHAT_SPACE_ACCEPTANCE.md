# 内置 Chat 单空间验收（2026-11-14）

## 已实现行为

- 同一本地账号进入固定 Chat，取消旧会话列表、新建、重命名、搜索和归档入口。
- 设置中切换群聊与好友列表。群聊呈现真实派工、Worker 回复与 Router 答复；好友列表里的 Worker 上下文只读，输入框提示“请与 Router 对话”。
- 同一输入草稿跨设置、视图及好友切换保留。Worker 记录按参与者分页，不受群聊最近 100 条消息的窗口限制。
- 清空仅覆盖当前账号内置 Chat 当前及旧会话、关联记忆和执行上下文。独立外部入口数据与其他账号数据保留；外部入口由自己的插件删除。
- 清空复用撤销日志和历史清理：先停止使用旧数据，再停止相关执行，清理原生历史、管理文件及数据库。运行中的合并先核对；不支持原生删除时保持处理中，不假报完成。
- 其他打开的窗口通过 SSE reset 同步撤下旧内容。旧回调与旧数据库快照不能恢复已清空的内容。新 Chat 保留原入口绑定，显示偏好、连接和项目配置保留。
- 新协作消息记录发言者、接收者、任务与触发来源。旧 Worker 投递若缺少原聊天归属，不依据任务现在的负责人反推补录。

## 证据与复核

`npm run check`：96 个测试文件，1455 通过、1 跳过（已有跳过项）。随后补充旧 Worker 投递归属回归，`npx vitest run tests/chat.spec.ts`：45 通过。最后的样式调整重建成功，Python 浏览器脚本语法检查通过。

`tests/browser/chat-space.py`：6 组流程通过，覆盖群聊、只读好友窗口、固定聊天和草稿、浅深主题/390px、确认清空/多窗口同步/重新提交，以及清空后继续切换视图。`tests/browser/agent-memory.py`：11 组记忆设置兼容流程通过。未出现浏览器 page error；记忆脚本额外核对 console，仅记录裸宿主已有的可选发现接口 404。

截图经过人工查看；设置单选按钮尺寸、危险操作颜色和窄屏边界再次读取验证。设计检测无主问题；两个建议（硬编码颜色、11px 字号）已改为现有语义颜色和 12px 字号。

后端回归覆盖相同范围里的外部入口保留并继续接收消息、其他账号隔离、重复清空请求、旧回调、停止运行中的非 scoped Router、保留原入口授权、合并预检、恢复旧数据库快照及历史 Worker 归属。

## 验证边界

浏览器使用隔离宿主、真实 HTTP/SQLite/执行工具调用和确定性模型回复。截图中的修复报告是测试模型内容，不是本次真实模型修复仓库的验收。未改动或清空用户运行实例，未向飞书等外部平台发消息，未合入或部署 main。

旧浏览器脚本中的会话操作已按固定 Chat 更新并检查语法；本次实际执行的是上述 Chat 与记忆脚本。当前代码的远端 CI 结果以对应提交的 GitHub Actions 为准。
