# O29a: acceptance-bound local saved methods

A saved method keeps its existing exact entry, scope, goal and final acceptance
identity. Listing, reading and reusing a version revalidate the source with the
existing read-only verification path. Replaced contracts, missing original
authority, withdrawn inputs and changed evidence no longer qualify that version
for display or reuse. A retired record remains retired. Prior authorization,
security rules and the fresh-request check for execution are unchanged.

The inspection separates the original acceptance from independent same-version
trial results. Only current final passes count as passed runs; a current failed
or insufficient round of a held same-version run counts as one counterexample.
The inspection exposes aggregate verdict/check counts and verification methods,
not raw evidence, filenames, review commentary or trial inputs. Fixed inputs
and parameterized trials are not presented as evidence of generalization.
Legacy versions lack a verified source-equivalence marker and are treated as
candidates until a qualifying trial passes.

This is a local saved-method slice. It does not generate learning instructions,
add tools or scripts, activate memory items, or import external data.

## O29b: manual, unreviewed outside notes

In personal memory settings, explicitly select an eligible private Chat and
paste an outside note as plain text with a source label. The label is not
verified, interpreted as authorization, or fetched. Each chat can hold up to
20 pending notes; each note is limited to 4,000 characters and its label to
200. The panel lists notes on request and allows discarding individual notes.
Closing the panel or switching chats drops the displayed copy.

Every request resolves the current signed-in owner, private conversation,
entry binding and actor. The notes live in a separate record namespace and
are not returned in ordinary memory, search, exports, working methods,
prompts, tools or policy. They are displayed only as text. This slice has no
promotion, document/network import, or automatic activation.

Discard removes the text and label from the live record and keeps an
operation tombstone to prevent replay. Chat reset and full history deletion
select these records by trusted conversation/scope metadata, not pasted
references, and use the existing cleanup ledger. This does not delete the
original source or copies in older exported backups.
