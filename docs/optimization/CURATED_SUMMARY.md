# O16：人工跨渠道摘要

在已登录宿主的 Router 管理页中打开「人工跨渠道摘要」。选择原会话和唯一目标，亲手填写可公开给该目标的精简摘要，核对平台、连接账号、入口和线程，再明确勾选确认。预览不入队也不向连接器发请求。该流程只发送此次确认的文本，不读取原对话、知识、附件、任务/Worker 输出，不调用模型，也不会广播或回退到另一会话。

目前仅列出最近 24 小时内有近期准入人类消息且仍有效的入口/线程，列表是有限的。来源和目标必须属于同一当前管理范围，但不是同一个入口或同一连接账户下的同一个房间；外发目前限已配置并绑定账号的飞书、Slack、企业微信。连接器按其现有会话/线程语义发送。如果新目标没有可核对的消息，不允许手输房间地址绕过绑定。

预览只在当前宿主进程保存五分钟。确认后，消息与审批收据在同一 SQLite 事务入队，收据绑定操作员会话、两端配置和权限及确切摘要。同一编号的重复确认只返回原状态。实际发送前再验证原会话与目标；来源删除、入口撤权、权限或配置版本变化、审批过期时阻止发送。站内操作者输入的摘要属于外发正文，不应粘贴源聊天原文。发送后无法由此功能撤回平台上的内容。

「入队」不等于送达；连接器返回错误或宿主在发送中退出时，记录为不确定，不自动重试，也不支持从通用重试入口重放。请保存记录编号，核对目标平台后再作决定。首次确认入队后数据库标记为 schema 21，防止不识别此审批约束的旧版宿主继续处理队列；不可用旧版直接打开该数据库。升级或回滚需采用正常备份流程，不要手工降级 schema。

验证范围：此实现提交未实测连接器、未运行测试、未构建部署。O16 验收应覆盖预览不发送、改目标/串会话确认、撤权/删消息/过期、双击确认、宿主重启、连接器结果不明以及真实线程回执。适配器本身的权限和平台收件语义仍以各自配置和真机验收为准。
