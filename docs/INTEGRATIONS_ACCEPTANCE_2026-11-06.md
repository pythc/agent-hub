## 完成范围

- 用 `SourceRegistry` 注册内置和外置适配器。CLI 启动及配置重建均使用异步加载入口；未知类型、重复注册、插件配置错误明确失败并释放状态锁。
- 保留 GitHub、飞书和企微实现，把创建、来源检查、游标回放、引用识别及初始任务绑定放入适配器接口；保留旧资源别名兼容。
- HTTP 事件保留来源身份、监听范围、原消息引用、附件引用及回复话题，加入跨重启完整事件去重。事件、回复、资源读取独立开关。
- 实现出站 MCP stdio / Streamable HTTP 工具消费，按 Worker 授予连接及确切工具名单，实际发现 schema、校验参数并执行。接入与模型 API、用户消息入口分离。
- 工具调用保存执行前记录及结果回执。并发 / 重启重试幂等；断线、超时、取消及中断结果不确定时不自动重做。回执可以按任务读取。
- 提供插件示例、Terra medium + 四个 Sol high 的配置示例和接入 / 升级 / 回滚文档。

## 自行审查发现并修复

1. 平台逻辑抽离时，GitHub 的“仅提及”默认行为和资源别名会话边界出现回归。保留原测试，改由注册器提供对应策略，恢复既有行为。
2. 原有持久 Router 在续办已完成的 Worker 任务时，直接附加用户事件，会把外部回复渠道引入 Worker。现在保留原用户事件，另建 Router 内部指令；宿主发送前再按委派关系统一路由所有 Worker 消息。
3. 对旧队列的修复只重定向尚未发送的消息；已经不确定的外部发送保留原状态和目的地，不伪装成内部已完成。
4. MCP 断线处理按连接实例清理，避免一个旧调用移除后来建立的连接；关闭宿主时中断初始化与在途调用。Schema 默认按 2020-12 校验，不默默忽略该版本的约束。
5. 推送型插件即使启动周期已结束，仍收到宿主关闭信号；异步启动失败进入来源健康记录，不产生未处理的 Promise 拒绝。
6. 拒绝不存在的工具连接，以及直接授予 Router、实际不会执行的 MCP 连接配置。
