# Roppo CLI 产品边界

更新：2026-11-26。交互界面以 OpenCode 为参考，使用 OpenTUI；功能围绕 Roppo 的个人助手定位。CLI 与网页共享账号、个人对话、记忆、文件和后台执行。

## 用户体验

- 从任意目录启动都继续个人对话。当前目录只用于附件和本地偏好；`--cwd` 是显式项目兼容入口。
- 主界面显示用户与 Router 的公开消息。Worker 的内部对话、分派和回传由现有宿主管理，执行详情在 `/tasks` 中按需查看。
- 空对话使用居中标识和输入区，不填充可滚动空行。有历史时直接续聊。消息滚动和输入草稿独立管理。
- `/` 提供输入旁补全；Ctrl+P 打开集中命令搜索；设置、模型、记忆、文件使用浮层。退出浮层后保留原草稿和光标。
- 待授权操作、提问和文件交付展示明确状态，可通过 Ctrl+Y 处理。选择和自定义回答在终端完成。
- 活动条只在实际执行或网络请求期间更新；等待用户时暂停，完成后收起。回复来自真实宿主事件。用户翻看历史时停止自动跟随。
- 默认英文，中文界面可选；回复语言由对话决定。支持跟随终端配色、深色、浅色、单色与减少动效。
- 退出终端保持服务运行。显式中断仍调用宿主取消接口。

## 与仓库的对应关系

`src/chat.ts` 的 `space()` 维护共享个人对话。`src/terminal/client.ts` 继续使用现有消息、附件和事件流协议，`conversation.ts` 保留公开消息过滤规则。

新增 `tui.ts` 管理连接和生命周期，`tui-screen.ts` 管理原生组件、布局、输入和浮层，`tui-actions.ts` 将用户操作接到实际宿主接口。旧 ANSI 编辑器保留为 `ROPPO_LEGACY_TUI=1` 回退路径及普通终端兼容路径。

`personal-account.ts` 只增加个人记忆、计划、审批和文件确认的有限路由；身份、所有权、版本冲突和执行权限仍由宿主验证。模型与权限修改影响共享账号，进行中的 Router 轮次保持原绑定。

## 个人助手能力

- 文件：查看交付文件，文本预览，选择本机路径保存；不覆盖已有文件。
- 记忆：读取真实个人记忆，编辑或明确确认后忘记，与网页同步。
- 计划模式：`/plan` 先澄清需求，再给详细计划；服务端禁用本轮工具与 Worker 派发。切回执行模式后，还需用户发送执行指令。
- 计划事项：`/schedules` 读取提醒和最近结果，暂停/恢复；新建和修改要求通过同一段对话表达。
- 设置：`/model`、`/effort` 先选择 Router 或具体 Worker；`/rename` 修改 Worker 名称；`/diff` 选择 Worker 和任务查看 Git 改动。
- 清理：`/clear` 默认取消，确认后清理消息和工作上下文，保留长期记忆、计划事项、文件和任务审计记录。
- 搜索：`/history` 和 Ctrl+K 查找当前对话内容，支持继续加载更早记录。
- 确认：处理原生权限请求、结构化问答、Router 选项、业务决策和待确认文件；不要求用户填写内部 Worker ID。

## 运行与兼容

服务和脚本输出继续支持 Node 22.19+。交互入口自动使用项目依赖中的 Bun 运行 OpenTUI，不需要全局安装 Bun。`-p`、JSON/NDJSON、显式项目入口等脚本入口保持兼容。交互界面的 `/resume`、`/new` 已移除会话切换能力。

当前支持 Plan/Act 对话模式，没有项目标签页或 Worker 会话列表。终端原型并不等价于 OpenCode 的全部功能；外部编辑器、Vim、图片剪贴板、插件安装等未实现的入口不展示为可用。

本次没有删除项目文件。具体用法见 [终端使用说明](TERMINAL.md)，验证范围见 [CLI 兼容说明](CLI_COMPATIBILITY.md)。
