# README artwork

## Roppo hero

- Asset: [roppo-hero.png](roppo-hero.png).
- Created with the built-in OpenAI image generation tool on 2026-11-07.
- Reference: the project's existing [Roppo mark](../../src/ui/assets/roppo-mark.png).
- Purpose: an original monochrome brand illustration, not a screenshot or a literal runtime topology.
- Used without post-generation image editing.

Prompt:

> Use case: brand editorial banner. Transform the supplied Roppo mark into a polished horizontal GitHub README hero banner, retaining the exact recognizable rounded R silhouette as the small logo next to the wordmark. Asset: a very wide 3:1 landscape banner, target 2400 by 800. Entire background pure white with extremely subtle neutral soft shadows, monochrome black, white and silver only, no colored accents. Composition: left 46% has generous negative space and immaculate Swiss-style typography. At x about 8%, centered vertically, a small black supplied R mark followed by the large word 'Roppo' in a bold modern sans serif. Below it on two lines, clear large text exactly: 'One conversation.' and 'A team of agents.' Right 50% has one beautifully crafted shallow isometric sculptural illustration of agent coordination: one larger near-black rounded square controller hovering at the center, its top embossed with the supplied R silhouette in white, four smaller off-white rounded square tool tiles neatly arranged around it, connected with fine dark flowing paths with subtle silver light beads. Each small tile has just one simple dark symbol, a document, a globe, code brackets, and a checkmark. The composition feels precise, architectural, calm and premium, like carefully art-directed open-source product branding. Keep everything readable at a GitHub content width of 840px. No mock screenshots, no metrics, no charts, no extra labels, no robots, no neon, no purple, no gradients of color, no extra slogan, no watermark. Keep a generous safe margin; do not crop wordmark or tiles. This is a brand illustration, not a functional diagram.

## Editorial references

Their artwork and product copy were not reused.
