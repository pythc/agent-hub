## 关键回归与自行复核结果

| 边界 | 已观察到的行为 |
| --- | --- |
| 功能关闭、空 patch、旧设置客户端 | 不生成身份或服务监听；保持旧配置形状和 schema；省略 teamTargets 不删除连接 |
| 重复提交、合同变更、ACK 丢失 | 同一任务 / Worker 执行不重复；不同内容冲突；先查原任务再决定是否提交 |
| 停止乱序 | 先到的取消形成 tombstone；后到提交不重新开工；迟到结果不恢复父任务 |
| 撤权 | 消费过的配对码不能重新授权；旧 Router 不能读缓存正文；出站撤权后仍可用固定身份核对取消 |
| 多任务与作用域 | 两个上游使用相同请求标识仍互相隔离；未授权 target、Worker 配置和其他任务引用不能泄露 |
| 租约失联与重连 | 到期停止；重连读取实际终态，不持续盲目续租；后来取消的控制代次也能得到确认 |
| 候选结果 | 早于报告读取的回复不能完成任务；候选就绪后不能再次激活；父级接受必须读取当前证据 |
| 产物 | 返回真实字节并核验摘要；正文中的文件名不能替代结构化声明；即使来源目录包含宿主状态，也拒绝私有身份文件 |
| 身份与恢复 | 重启保留身份 / 授权 / 服务端口；恢复后保持隔离，摘要变更拒绝确认；旧连接必须重新配对 |

实现期间真实模型的前两轮未通过：先发现缺少内部文件捕获工具，再发现模型将文件写入正文却遗漏结构化声明。分别补上 `superagent_artifact` 和必填的显式产物列表后重新验证，没有放宽权限来获得通过。另一次启动发现 Zod 默认数组的 schema 取值错误，在发起模型请求前失败，已修正。旧配置默认值回归、负向工具调用断言及浏览器兼容探测也分别修正或明确分类，失败目录均保留。
