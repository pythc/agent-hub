# Getting help

Use [GitHub Discussions](https://github.com/pythc/agent-hub/discussions) for setup questions, usage advice, and workflow sharing. English and Chinese are welcome.

Use an [issue form](https://github.com/pythc/agent-hub/issues/new/choose) for a reproducible defect or a concrete feature request. Include your commit or version, operating system, Node version, backend type, minimal steps, and expected versus observed behavior. Redact secrets and personal data from logs and screenshots.

Start with the [README](README.md), [operations guide](docs/OPERATIONS.md), and [model guide](docs/MODELS.md). Provider billing, eligibility, website login expiry, and CLI account access are controlled by their providers.

For sensitive reports, follow [SECURITY.md](SECURITY.md). This is a community-maintained project with no guaranteed support response time.
